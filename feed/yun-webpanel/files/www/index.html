Wi-Fi networks

The Yún joins one network as a client. While it's in setup mode, it runs its own open network instead.

    Join network

    The Yún will drop off this network while it switches. If it can't join within a minute after rebooting, it goes back to setup mode.

    Setup mode

    Turn the Yún back into an open access point called Arduino Yun, reachable at 192.168.240.1. Holding WLAN RST for 5 seconds does the same.

    Ethernet

    The Ethernet port gets its address from your router (DHCP).
